# Personal Finance Tracker - Requirements

## 1. Project Objective

The Personal Finance Tracker is a web-based application
that allows users to manage their personal finances.

Users can record their income and expenses, create budgets,
set financial goals, and monitor their financial activities
through a dashboard.

## 2. Target Users

The system is designed for individuals who want to
manage and monitor their personal finances.

## 3. Functional Requirements

### Authentication

- User registration
- User login
- User logout

### Transaction Management

- Add income
- Add expenses
- View transactions
- Update transactions
- Delete transactions
- Search transactions
- Filter transactions

### Category Management

- Create categories
- View categories
- Update categories
- Delete categories

### Budget Management

- Create budgets
- View budgets
- Update budgets
- Delete budgets
- Track budget usage

### Financial Goals

- Create financial goals
- Update financial goals
- Delete financial goals
- Track goal progress

### Dashboard

- Display total income
- Display total expenses
- Display current balance
- Display spending by category
- Display budget status
- Display financial goal progress

## 4. Non-Functional Requirements

### Security

- Passwords must be securely hashed.
- Authentication must be implemented.
- Protected resources must require authentication.

### Performance

The system should respond to normal user requests
within a reasonable amount of time.

### Usability

The application should have a simple and user-friendly interface.

### Maintainability

The system should follow a layered architecture and
maintain clean and readable code.
